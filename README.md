## Principles

- Evidence first; no fabricated data.
- Publish methods before results.
- Report limitations and corrections.
- Do not mix market coverage in one trend line without labeling it.

## Status

This repository mirrors public assets for citation and archival. Client data and client-identifying evidence are never published here.
